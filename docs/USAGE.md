# CV Tailor AI - Usage Guide

## Overview

CV Tailor AI automates the process of adapting your CV for specific job opportunities using LLM intelligence.

## Quick Start

### 1. Installation

```bash
git clone <repo-url>
cd cv-tailor-ai-ts
npm install
echo "OPENAI_API_KEY=your-api-key-here" > .env
npm run build
```

### 2. Prepare Your Base CV

Place your base CV HTML file in the `original/` directory:

```
original/
├── mr-cv-edreams.html      # Primary CV
└── MR_cv_athenailabs.html  # Alternative CV for React-heavy roles
```

### 3. Run the Adapter

#### From Text File

```bash
npm start -- --file offers/job_offer.txt
```

#### From URL

```bash
npm start -- --url "https://company.com/careers/frontend-developer"
```

#### From Direct Text

```bash
npm start -- --text "Senior Frontend Developer needed with React experience..."
```

> Note: `--text`, `--file`, and `--url` are mutually exclusive — provide exactly one.

### 4. Get Your Adapted CV

Find your tailored CV in:

```
output/Miguel-Rivero-Lopez-{job-title}.html
```

## Advanced Usage

### Custom Base CV

```bash
npm start -- --file offers/job.txt --base original/custom_cv.html
```

### Framework Emphasis

Use `--framework` to control how framework experience is presented
(`react` | `vue` | `agnostic`, default: `agnostic`):

```bash
# Emphasize quick, confident ramp-up to React (primary experience is Vue)
npm start -- --file offers/job.txt --framework react

# Emphasize Vue experience specifically, without mapping to React
npm start -- --file offers/job.txt --framework vue

# Framework-agnostic: stress general frontend framework experience
npm start -- --file offers/job.txt --framework agnostic
```

### Custom Output Directory

```bash
npm start -- --file offers/job.txt --output-dir my_cvs
```

### Verbose Mode

```bash
npm start -- --file offers/job.txt --verbose
```

### Skip Watermark Check

```bash
npm start -- --file offers/job.txt --no-watermark-check
```

## Understanding the Process

### Step 1: Keyword Extraction

The system analyzes the job offer and extracts:

- **Hard Skills**: Technical abilities (e.g., TypeScript, Testing)
- **Soft Skills**: Interpersonal abilities (e.g., Leadership, Communication)
- **Technologies**: Tools and frameworks (e.g., React, Docker)
- **Responsibilities**: Key job duties
- **Synonyms**: Framework translations (Vue ↔ React)

### Step 2: Title Extraction

Extracts and normalizes the job title:

- "Senior Frontend Developer" → `senior-frontend-developer`
- "React + TypeScript Engineer" → `react-typescript-engineer`

### Step 3: CV Adaptation

Adapts your CV while:

- ✅ Preserving HTML structure
- ✅ Integrating relevant keywords
- ✅ Translating frameworks (Vue → React)
- ✅ Anonymizing company names
- ✅ Maintaining authenticity

### Step 4: Watermark Removal

Removes any AI-generated traces:

- "Generated by AI" ❌
- "As an AI model" ❌
- "This CV was adapted using" ❌

### Step 5: File Generation

Creates the final file:

```
Miguel-Rivero-Lopez-{job-title}.html
```

## Troubleshooting

### "Base CV not found"

Ensure your CV is in `original/` directory:

```bash
ls original/mr-cv-edreams.html
```

### "OpenAI API Error"

Check your API key:

```bash
echo $OPENAI_API_KEY
```

### "Watermarks detected"

Re-run with verbose mode to see detections:

```bash
npm start -- --file offers/job.txt --verbose
```

### "Invalid JSON from keywords extraction"

The LLM response may need cleaning. Check logs and retry.
