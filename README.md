# CV Tailor AI (TypeScript) 🎯

Automated CV adaptation system using LLM intelligence to tailor resumes for specific job offers - **TypeScript version with PDF support**.

## ✨ New Features in v2.0

- **📄 PDF Input Support**: Use PDF CVs as base documents
- **📑 PDF Output Generation**: Export adapted CVs as PDFs
- **🔷 TypeScript**: Full TypeScript implementation with type safety
- **⚡ Modern Stack**: Node.js 18+, ESM modules, latest dependencies

## Features

- **Intelligent Keyword Extraction**: Analyzes job offers to extract relevant skills and technologies
- **Structure-Preserving Adaptation**: Modifies only text content while maintaining HTML structure
- **React/Vue Translation**: Handles framework mismatches elegantly
- **Anti-Watermark Protection**: Ensures zero AI traces in output
- **Auto-Naming**: Generates filenames based on job title
- **Company-Agnostic**: Never mentions target company name explicitly
- **PDF Support**: Read PDF CVs and generate PDF outputs

## Quick Start 🚀

### Installation

```bash
# Clone the repository
git clone <repo-url>
cd cv-tailor-ai-ts

# Install dependencies
npm install

# Set up your OpenAI API key in .env file
echo "OPENAI_API_KEY=your-api-key-here" > .env

# Build the project
npm run build
```

### Usage

#### Basic Usage (Default: PDF Input → HTML & PDF Output)

```bash
# From job offer URL
npm start -- --url "https://example.com/job-posting"

# From job offer text file
npm start -- --file offers/job_offer.txt

# From direct text
npm start -- --text "Senior Frontend Developer..."
```

#### Custom PDF Input

```bash
# Use a specific PDF CV as base (when omitted, the HTML --base CV is used)
npm start -- --url "https://example.com/job" --pdf-input original/my_cv.pdf
```

#### Framework Emphasis

Control how the candidate's framework experience is presented with `--framework`
(`react` | `vue` | `agnostic`, default: `agnostic`):

```bash
# React-focused role: convey quick, confident ramp-up to React
npm start -- --file offers/job.txt --framework react

# Vue-focused role: emphasize Vue experience specifically
npm start -- --file offers/job.txt --framework vue

# Framework-agnostic (default): stress general frontend framework experience
npm start -- --file offers/job.txt --framework agnostic
```

The CLI always sends one of those three modes. The web app is different: see below.

#### HTML Output Only

```bash
# Generate only HTML output (skip PDF generation)
npm start -- --url "https://example.com/job" --html-only
```

#### Advanced Options

```bash
# Enable verbose output
npm start -- --file offers/job.txt --verbose

# Skip watermark detection check
npm start -- --file offers/job.txt --no-watermark-check

# Custom output directory
npm start -- --file offers/job.txt --output-dir my_cvs
```

### Output

The adapted CV will be saved to:

```
output/Miguel-Rivero-Lopez-{job-title}.html  (Always generated)
output/Miguel-Rivero-Lopez-{job-title}.pdf   (Generated by default, skip with --html-only)
```

### CLI Options

| Option                 | Description                                                                       |
| ---------------------- | --------------------------------------------------------------------------------- |
| `--text TEXT`          | Provide job offer text directly (mutually exclusive)                              |
| `--file PATH`          | Path to job offer text file (mutually exclusive)                                  |
| `--url URL`            | URL of job offer page to parse (mutually exclusive)                               |
| `--base PATH`          | Path to base CV HTML file (default: `original/MR_cv_base.html`)                   |
| `--pdf-input PATH`     | Path to base CV PDF file; when omitted, the HTML `--base` CV is used              |
| `--framework MODE`     | **NEW**: Framework emphasis: `react` \| `vue` \| `agnostic` (default: `agnostic`) |
| `--html-only`          | **NEW**: Generate only HTML output (no PDF attempt)                               |
| `--output-dir DIR`     | Output directory (default: `output`)                                              |
| `--verbose`, `-v`      | Enable verbose output with detailed progress                                      |
| `--no-watermark-check` | Skip watermark detection check                                                    |

## Web app

```bash
npm run dev:web
```

Open **http://127.0.0.1:5180/cv-tailor-ts/** (the `/cv-tailor-ts/` path is required).

React / Vue / Agnostic framing is shown only when the base CV is the default, `original/MR_cv_base.html`. The blank template and an uploaded HTML file hide that control. The request then omits `framework`, and the worker uses career-neutral prompts: it rewrites only what is already in that HTML, with no Vue-to-React framing. Upload accepts HTML in the `.content` + `shared.css` layout, not PDF. The blank template is `original/cv_template.html`. Details: [docs/WEB.md](docs/WEB.md).

## Configuration ⚙️

Edit `config.yaml` to customize:

```yaml
model: 'gpt-4o'
temperature: 0.7
base_cv: 'original/MR_cv_base.html'
shared_css: 'original/shared.css'
fallback_cv: 'original/MR_cv_athenailabs.html'
output_dir: 'output'

# PDF Configuration
pdf:
  enabled: true
  format: 'A4'
  print_background: true
  margin:
    top: '0'
    right: '0'
    bottom: '0'
    left: '0'
```
